# assets

Source art for the game. Nothing in here is synced into Roblox yet: neither
Rojo project file (`default.project.json`, `lobby.project.json`) references
this folder.

| Folder | For |
|---|---|
| `maps/` | Battlegrounds: one subfolder per map |
| `units/` | Unit models, rigs and animations: one subfolder per unit type |
| `factions/` | Faction-wide art: uniforms, colours, emblems |
| `skins/` | Earnable / purchasable cosmetic variants (future) |
